# AUREL — The World, Beyond Ordinary

Landing page for AUREL, a luxury travel house. Plain HTML, CSS and JavaScript with GSAP, ScrollTrigger and Lenis for the scroll animations. Built for desktop.

Live site: https://aurel-landing-page.vercel.app (Vercel) · https://murtuza6769-art.github.io/aurel-landing-page/ (GitHub Pages)

## Run it locally

Open `index.html` in Chrome or Edge. Keep the `assets` folder next to it: it holds the photos, films and animation scripts.

## Before launch

The testimonials, journey prices, address, phone number, email and social links are sample content and need replacing.
